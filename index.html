시연 2

96회 실험 동안 AI와 실험계획법이 최적 조건에 다가가는 과정

4변수 가상 반응 모델에서 30번씩 반복한 시뮬레이션 결과(중앙값과 사분위 범위)를 그대로 재생합니다. 실험계획법(RSM)은 조건마다 가장 성적이 좋았던 변형입니다.

96회

96웰 플레이트 진행

무엇을 보여 주는가. 시연 1은 제안서 5번 항목의 시제품(agent/)을 브라우저로 옮긴 것으로, 36개 사례에서 Python 원본과 판정·사유가 모두 일치하는 것을 확인했습니다. 시약 유해성·인화점·재고는 공개 SDS 대표값을 옮긴 시연용 값입니다. 1회차 배치는 브라우저에서 새로 뽑은 라틴 하이퍼큐브 예시입니다.

시뮬레이션의 한계. 시연 2는 합성 반응 모델 기반 가상 시뮬레이션이며 실제 실험 데이터가 아닙니다. 96회 후 최종 수율은 AI와 실험계획법이 비슷했고, 차이는 목표 도달 속도에서 났습니다. 한 회차 24웰 조건에서는 실험계획법이 조금 더 나았습니다.
